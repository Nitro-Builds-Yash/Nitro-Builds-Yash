## 🧠 Multi-Modal AI & Knowledge Systems

### **[OmniChunk](https://github.com/Nitro-Builds-Yash/OmniChunk)**
> **Universal AI Multi-Modal Chunking & Relational Structure Extraction Platform**  
> Profiles documents, audio, tables, and media before cutting. Anchors captions to figures, reconstructs hierarchical heading ancestry, vetoes relationship breaks, and generates audit decision receipts.
> *Tech Stack: Python, FastAPI, Docling, NetworkX, PyTorch, Sentence-Transformers, TailwindCSS, HTMX*

### **[halo](https://github.com/Nitro-Builds-Yash/halo)**
> **Production-Ready Self-Corrective Agentic QA Assistant**  
> Upload PDFs (research papers, manuals, policies) and run multi-document reasoning with autonomous hallucination gates, confidence scoring, citation verification, and Reciprocal Rank Fusion.
> *Tech Stack: Python, LangChain, Vector DB, RAG Architecture, LLM Evaluation*

### **[voxcode](https://github.com/Nitro-Builds-Yash/voxcode)**
> **Voice-Assisted AI Coding Agent**  
> Conversational software development assistant that understands codebases using AST symbol extraction, BM25 + dense hybrid search, plans and generates edits, and reviews results with STT/TTS integration.
> *Tech Stack: Python, Speech-to-Text / TTS, AST Parsing, Hybrid Retrieval, VS Code Workflow*
